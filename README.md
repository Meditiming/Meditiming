# MediTiming

> **수업용 시제품입니다.** 수업 과제로 만든 연습용 화면이며, 실제 의료 서비스가 아닙니다.

## 서비스 소개

- 약마다 다른 복용 시간을 등록해 두면, 시간에 맞춰 알림을 받고 먹은 약을 기록할 수 있습니다.
- 이미 먹은 약을 다시 기록하려 하면 중복 복용 경고를 보여 주고, 날짜별 복용 기록을 달력으로 확인할 수 있습니다.
- 약과 영양제를 함께 먹어도 되는지 궁합을 확인하고, 약을 놓치면 보호자에게 보낼 안내 문자를 만들어 보여 줍니다.

## 수업용 시제품 안내

- 이 저장소의 화면과 데이터는 수업용 시제품입니다. 실제 복약 판단에 쓰지 마세요. 약에 대한 판단은 의사나 약사와 상담해 주세요.
- 약 궁합 정보는 화면 시연용 예시이며, 검증된 의약품 데이터가 아닙니다.
- 보호자 문자는 실제로 보내지 않고, 보낼 내용을 화면에 미리 보여 주기만 합니다.
- 모든 데이터는 `가상 사용자 1`, `가상 약 1` 같은 가상 데이터입니다. 실제 개인정보나 환자 정보는 들어 있지 않습니다.
- 입력한 내용은 서버로 보내지 않고, 사용하는 브라우저 안에만 저장됩니다.

## 실행 방법

`medication.html` 파일을 브라우저에서 엽니다. 설치나 서버가 필요 없습니다.

- 글꼴과 사진 글자 인식 도구를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
- 복용 알림은 화면을 열어 둔 동안에만 나옵니다.
- 오른쪽 위 버튼으로 한국어와 영어를 바꿀 수 있습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `medication.html` | MediTiming 서비스 화면 (HTML, CSS, JavaScript가 한 파일에 들어 있습니다) |

| `기획서.md` | 서비스 기획서 |
